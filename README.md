# sundry-claude-mods

직접 만든 Claude Code 모드 모음입니다. 이 레포가 곧 마켓플레이스입니다.

| 모드 | 내용 |
|---|---|
| [session-flow](session-flow/README.md) | 세션에서 시킨 일과 그 흐름을 한 줄씩 보여 주는 로그 창 |

```bash
claude plugin marketplace add hham21/sundry-claude-mods
claude plugin install session-flow@sundry-claude-mods
```

레포를 클론해 그 폴더 경로로 추가하면, 모드 코드를 고친 뒤 세션에서 `/reload-plugins`로 바로 반영됩니다.
